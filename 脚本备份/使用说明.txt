智慧养老手表管理系统 —— 使用说明
========================================

一、这是什么
SpringBoot + Vue 的智慧养老手表管理系统，通过智能手表监控老人的
血压、心率、睡眠、摔倒报警等，含家属端和医院/管理员端。
另外提供「手表端（设备侧）接口」，鸿蒙手表或模拟手表都能往系统里上报数据。

二、目录结构
  careold/       后端（SpringBoot 1.5.19，端口 8795）
  oldIot/        前端（Vue2 + ElementUI + webpack3，端口 8087）
  watch-sim/     模拟手表（Node 脚本，无真机时用它产生实时数据）
  old.sql        数据库脚本（MySQL，库名 old）
  tools/         内置 Node 10 便携版（前端运行时，无需另装 Node）
  careold/target/careold-0.0.1-SNAPSHOT.jar   已编译好的后端 jar
  启动系统.bat       一键启动（MySQL + 后端 + 前端 + 自动开浏览器）
  停止系统.bat       一键停止
  一键导入数据库.bat  首次使用：双击即可导入 old.sql
  升级数据库（添加邀请码）.bat  老库补齐邀请码表（用过旧版数据库时执行一次）
  升级数据库（添加设备表）.bat  老库补齐设备手表相关表（用过旧版数据库时执行一次）
  启动模拟手表.bat    启动模拟手表，让页面数据实时变化
  启动后端.bat / 启动前端.bat   可单独启动

三、怎么运行
首次使用（只需做一次）：
  1. 装好 MySQL 和 JDK（后端运行需要 JDK，见“启动后端.bat”顶部路径）。
  2. 双击“一键导入数据库.bat”，导入 old.sql。
  3. 如果你之前已经导入过旧版数据库，请再双击下面两个脚本补表：
     “升级数据库（添加邀请码）.bat”
     “升级数据库（添加设备表）.bat”
以后每次：
  1. 双击“启动系统.bat”。
  2. 浏览器自动打开 http://localhost:8087/
  3. （可选）双击“启动模拟手表.bat”，页面上就会看到实时数据。

五、家属自己注册（邀请制）
  本系统不开放自由注册，家属账号必须由管理员发放邀请码后才能注册。
  1. 管理员登录后，左侧菜单进入“后台管理 -> 邀请码管理”。
  2. 点“生成邀请码”，选择要绑定的老人，可设置生成数量和有效天数
     （有效天数留空表示长期有效），点“生成”。
  3. 把生成的邀请码复制下来发给家属（每个邀请码只能使用一次）。
  4. 家属打开登录页 http://localhost:8087/ ，点“注册账号”，
     填写邀请码、姓名、与老人关系、性别、手机号、密码、地址，提交即可。
  5. 注册成功后系统自动把该家属绑定到邀请码指定的老人，
     家属用“手机号 + 密码”登录，进入家属端。
  提示：
  - 邀请码输入时不区分大小写，注册页会实时校验并显示绑定的老人。
  - 邀请码用过一次就失效；过期或被管理员作废的邀请码不能再用。
  - 提醒家属不要重复注册：同一个手机号只允许注册一次。

六、手表（设备）怎么接入
  系统里的“手表”可以是真的鸿蒙手表，也可以先用模拟手表。
  1. 管理员登录后，左侧菜单“基础管理 -> 设备管理”。
  2. 每台设备都有”设备号 + 密钥“（系统预置了 3 台演示设备：
     WATCH0001 / demo-secret-1 等，绑定在示例老人身上）。
  3. 要给新手表绑定老人：点该设备的“绑定码”，选择老人并“生成绑定码”，
     得到一个 6 位码（默认 1 天有效，只能用一次）。
  4. 在手表端（或模拟手表）输入这个绑定码，即完成绑定。
  5. 绑定后手表按“设备侧接口契约.md”里的接口上报，页面就会实时更新：
     心率血压、睡眠步数、位置信息、摔倒告警、在线状态与电量。
  6. 没有真机时：直接双击“启动模拟手表.bat”，详见
     “模拟手表使用说明.md”。

七、局域网演示（手表和电脑连同一个 Wi-Fi）
  - 后端已经监听所有网卡，端口 8795，并已添加 Windows 防火墙入站规则。
  - 手表端/模拟手表的服务器地址填：http://电脑局域网IP:8795
    （本机当前为 http://10.239.21.82:8795，换网络后 IP 会变，
     用 ipconfig 查看“无线局域网适配器 WLAN”的 IPv4 地址）。
  - 网页端仍在本机浏览器访问 http://localhost:8087/ 。
  - 若要换一台电脑看网页，需把“启动前端.bat”里的 host 改成 0.0.0.0。

八、环境要求（打包/迁移到新机器时注意）
  - 后端运行需要 JDK：本机在 C:\Program Files\Java\jdk-17，
    若不同请编辑“启动后端.bat”顶部的 JAVA_HOME。
  - 前端已内置 Node 10 便携版（tools 目录），无需额外安装 Node。
  - 数据库需 MySQL 5.x / 8.x。注意：MySQL 8 的 sql_mode 已去掉
    ONLY_FULL_GROUP_BY（配置文件 my.ini，改动前的备份为 my.ini.bak-20261012），
    因为系统里 2019 年写的分组查询在严格模式下会报错。

九、重新编译后端（可选，一般不需要）
  后端 jar 已经编译好。若修改了后端代码需要重编，需要 Maven：
      cd careold
      mvn -DskipTests package

十、本次适配改动说明（为什么能在这台机器跑起来）
  - 删除了 OldPersonController.java、WatchInfoController.java 中无用的
    javafx.beans.property.IntegerProperty 导入（JDK 11+ 已移除 JavaFX）。
  - 后端在 JDK 17 上需加 --add-opens 参数（脚本已内置），
    若改用 JDK 8 可去掉这些参数。
  - 前端 webpack3 + webpack-dev-server 2.9 需用旧版 Node（10.x）运行，
    已内置到 tools 目录。
